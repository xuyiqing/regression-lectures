# Data for lecture 6-3 (read by the scripts in `code/`)

| file | what it is | used by |
|---|---|---|
| `REPLICATION_DATA.asc` | 2000 presidential election, all 67 Florida counties, 47 columns (`name`, `TotalVotes00`, `buchanan00`, `gore00`, `bush00`, registration shares, census variables, model predictions `pr1`–`pr3`). The county file behind Wand et al. (2001), "The Butterfly Did It," *APSR* 95(4); the slides cite it as the data used in that article. Space-delimited with a header row: `read.table(f, header = TRUE)`. File dated 2002. | `fig_florida.R` |
| `gerber_reduced.dta` | Random subset of the Gerber, Green and Larimer (2008) Michigan social-pressure experiment: 14,392 registered voters in 7,599 households. Variables `voted` (No/Yes, August 2006 primary), `Tr_Hawthorne`, `Tr_CivicDuty`, `Tr_Neighbors`, `Tr_Self`, `hh_id`. Copied on 2026-09-17 from `../02-4MoreInference/code/data/` (file dated 2011). | `fig_gerber.R` |
| `gerber.dta` | The full experiment: 344,084 voters in 180,002 households (`treatment`, `voted`, `hh_id`, and more). Copied on 2026-09-17 from `../02-4MoreInference/code/data/` (file dated 2011). Used only for the full-sample within-household correlation quoted on the slide (.53). | `fig_gerber.R` |
| `colantone_stanig_bes_w8.csv` | British Election Study wave 8 (May 6 to June 22, 2016) respondents from the Colantone and Stanig (2018) *APSR* 112(2) replication data (Harvard Dataverse doi:10.7910/DVN/AL1A4Q, CC0): `leave` (intends to vote Leave), `import_shock` (Chinese import shock of the respondent's NUTS-3 region), `age`, `gender`, `nuts1`, `nuts3` and more. 16,331 rows with `leave`, `import_shock`, `age` and `gender`, in 167 NUTS-3 regions. Copied on 2026-10-11 from `../../../_data/brexit/` (built there by `build.R`; see its README). | `fig_brexit_cluster.R` |
| `donovan2020_monthly.csv` | Monthly series from the Donovan, Kellstedt, Key and Lebo (2020) *Political Behavior* 42(4) replication data (Harvard Dataverse doi:10.7910/DVN/MN4PT4, CC0): `ind` (presidential approval among independents, %), `bus5yr` (5-year business expectations, Index of Consumer Sentiment), administration dummies `reaganbush`, `clinton`, `gwb`, `obama`. 420 months; `ind` and `bus5yr` both present for January 1981 to August 2015 (416 months). Copied on 2026-10-11 from `../../../_data/papers/donovan2020/` (see its README for the codebook). | `fig_donovan.R` |

The Florida file is also read by `fig_florida_hc.R`.
